# 싹이의 생명 정원 🌱

초등학교 3학년 도덕 「7. 생명을 소중히 여기는 우리」에서 **생명 존중 전시회를 계획하는 활동**을 돕는 웹도구입니다.

## 실행하기

- **수업용 주소:** https://kyujinrunner.github.io/ssak-life-garden/
- 태블릿에서는 가로 화면으로 사용하세요. 전자칠판과 PC에서도 사용할 수 있습니다.
- 회원 가입이나 학생 로그인이 필요하지 않습니다.
- 인터넷 없이 쓰려면 `index.html`을 내려받아 브라우저로 여세요. 그림과 글꼴이 파일 안에 포함되어 있습니다. 온라인 주소를 처음 열 때는 인터넷 연결이 필요합니다.

## 활동 순서

1. **내 씨앗 심기:** 전시회 방법을 고르고, 누구의 생명을 왜 소중히 여기는지와 알리고 싶은 행동을 정합니다.
2. **우리 모둠 정원:** 모둠 번호와 씨앗을 고르고 전시회 계획을 함께 세웁니다.
3. **물 주기:** 생명에게 도움이 되는 점, 친구 의견을 반영한 점 또는 그대로 하는 까닭, 준비할 사람·물건·장소를 점검합니다.
4. **꽃 피우기:** 완성한 전시회 초대장을 화면에 띄워 캡처하거나 글을 복사합니다.
5. **오늘의 한 줄 생각:** 친구에게 배운 점이나 내가 실천할 생명 존중 행동을 적습니다.

앱은 입력의 유무를 확인하며, 생각의 옳고 그름을 자동으로 평가하지 않습니다. 대화와 교사의 피드백을 함께 진행하세요.

## 교사용 기능

- 왼쪽 위 **‘싹이의 생명 정원’ 글자를 빠르게 5번** 누르면 교사용 창이 열립니다.
- 장면 이동, 예시 채우기, 새로 시작, 저사양 모드를 사용할 수 있습니다.
- 소리는 기본으로 꺼져 있습니다. 오른쪽 위에서 켤 수 있습니다.
- 예시 미리보기: https://kyujinrunner.github.io/ssak-life-garden/#demo=1&scene=b3
- **‘예시로 채우기’와 ‘새로 시작’은 현재 브라우저의 활동 기록을 바꿉니다.** 학생의 기록을 확인한 뒤 사용하세요.

## 기록 저장과 개인정보

- 활동 내용은 사용 중인 기기의 브라우저 저장 공간(`localStorage`)에 저장됩니다.
- 웹도구에는 활동 내용을 서버로 보내거나, 다른 기기의 기록을 모으는 기능이 없습니다. 모둠 번호가 같아도 서로 다른 기기의 내용은 자동으로 합쳐지지 않습니다.
- 같은 기기·브라우저를 다음 학생이 사용하면 이전 활동 기록이 보일 수 있습니다. 활동을 확인하고 필요한 화면을 저장한 뒤 교사용 창에서 새로 시작하세요.
- 브라우저 데이터를 삭제하거나 사생활 보호 모드를 쓰면 기록이 보존되지 않을 수 있습니다. 주소나 브라우저가 달라져도 이전 기록을 가져오지 않습니다.
- 학생 실명·연락처·상담 내용 등 개인정보를 입력하지 마세요.
- 패들렛에 올리는 기능은 자동 전송이 아닙니다. 교사가 정한 공간에 화면을 직접 올리거나 글을 붙여 넣어야 합니다.
- GitHub Pages에서 페이지를 제공하는 과정의 접속 정보 처리는 GitHub의 정책을 따릅니다.

- `index.html`: 웹도구 전체. 별도 설치나 빌드가 필요하지 않습니다.
- `.nojekyll`: GitHub Pages에서 정적 파일을 그대로 제공합니다.
